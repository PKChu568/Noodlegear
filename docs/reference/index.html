Noodlegear design system

Visual reference for the Driving School Management System. Fluent 2 based, light theme by default, desktop-first.

Reference only.This page illustrates the intended look. Build the application with Fluent UI React v9 and the tokens in tokens/noodlegear.tokens.json, following docs/. Where this page and the docs differ, the docs win.
Principles
Function before form. Every element helps someone read, decide or act.
Consistency over novelty. The same thing looks the same everywhere.
Density with clarity: 34px rows, 14px text, 4px grid.
Restrained colour. Blue means interactive; status colours mean status.
Always
Fluent components and tokens. No raw colours or pixel values.
One page title and one primary button per view.
Status through the registry, always with a text label.
WCAG 2.2 AA, keyboard complete, both themes.
Never
Glassmorphism, gradients, glows, decorative shadows.
Large rounded cards, or cards around everything.
Purple/pink accents, random colours, illustrations.
Oversized type, decorative animation, charts without a question.

Icons

Fluent UI System Icons only. 20px Regular by default, 16px in cells and badges, Filled for selected navigation. One icon per concept.

Page header: right-aligned. Secondary, then overflow ⋯, then primary right-most.

Form controls

Every input is wrapped in a Field: label on top, 4px to the control, 16px between fields, 24px between columns. Errors explain how to fix the problem.
